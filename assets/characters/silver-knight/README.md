# 蒼銀騎士立繪

本批為本專案原創角色的 OpenAI 生成美術；沒有引用外部遊戲人物。先製作待機參考，再以同一參考生成四個姿態。生成 PNG 原稿保留在執行環境 /workspace/generated_images，網頁使用保留透明 alpha 的 WebP（quality 85），沒有手動重繪或裁切角色。

共同畫布 1024×1536，面向右；半寫實蒼銀盔甲、藍色面甲、深藍披風、長劍與風箏盾。逐姿態腳底錨點寫在 metadata.json 與 data/visuals.js，切換姿態使用相同角色比例。背景透明值為 0，主體最高 alpha 254；接近不透明，不能以必須恰為 255 誤判。

| 姿態 | 網頁檔 | 大小 bytes | 腳底 anchor.y |
|---|---|---:|---:|
| idle | idle.webp | 239,054 | 0.953125 |
| attack | attack.webp | 227,808 | 0.951172 |
| defend | defend.webp | 268,932 | 0.958984 |
| hurt | hurt.webp | 273,786 | 0.932292 |

合計 1,009,580 bytes，約 986 KiB。metadata.json 保存每張來源檔名、SHA-256、畫布、可見範圍、錨點與方向。原 PNG 不放入遊戲部署資源。

四張已製作與整合；使用者美術確認、實體低階裝置首次載入與縮小辨識度仍待驗收，不等同全部 21 張正式素材完成。五王、狂暴及五背景共 17 張尚待製作，仍使用占位圖。
