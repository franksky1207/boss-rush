# 遊戲標題字體

來源：Google Fonts 的 Noto Serif TC 可變字體（google/fonts，ofl/notoseriftc/NotoSerifTC[wght].ttf）。使用 SIL Open Font License 1.1，完整授權保留在 OFL-NotoSerifTC.txt。

網頁使用本機 WOFF 子集，字集取自 index.html、data、ui 與 GAME_DESIGN.md，保留字重軸。未含的玩家暱稱字元由系統字體補齊。font-display: swap，載入失敗不阻止遊戲。標題／招式／角色名與行動使用襯線字；數字、操作資訊維持清楚的介面字體。沒有執行期第三方字體請求。
