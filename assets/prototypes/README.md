# 第二、三批占位素材

本資料夾的 12 張 SVG 為本專案自行繪製的幾何原型，不含外部圖片。用途為測試輪廓、姿態、站位與裁切，**不是精緻半寫實正式美術，也不計入 21 張正式素材完成數**。

角色畫布均為 160×240，腳底錨點為 `(80, 240)`，面向與可見比例定義在 `data/visuals.js`。同一占位圖透過獨立武器、護盾與姿態變換模擬待機、攻擊、防禦、受傷。

日後替換正式角色：修改 `poses.idle / attack / defend / hurt`，並同步填寫 canvas、anchor、visibleBounds；各姿態須保持一致的腳底錨點及可見尺寸。朝向 `right` 是勇者基準，`left` 是 Boss 基準。圖片缺失時會保持角色尺寸並顯示幾何降級圖，不影響判定。

五王角色由 `BOSS_VISUALS` 指定，狂暴由 `BERSERK_VISUAL` 指定；五戰場由 `ARENA_VISUALS` 指定，以 cover 方式裁切。圖片失敗時保留幾何降級角色與 CSS 場景。
